# ConectaTutor

Plataforma web para conectar estudiantes que necesitan ayuda en una materia con estudiantes de semestres más avanzados que dan tutorías. Desde la Entrega 2 la aplicación está pensada para la Universidad de La Guajira (Uniguajira).

Proyecto de Desarrollo Web 2026-2, Línea 2. Trabajo individual de Shalem Rolón.

Prototipo en Figma: https://www.figma.com/proto/M63zFjGYVnZk1p1Y21V30r

## Carpetas

- `entrega-1/`: requisitos, historias de usuario, diagramas, prototipo de baja y alta fidelidad, pruebas con usuarios e informe.
- `frontend/`: aplicación web (React + Vite + Bootstrap 5). Instrucciones de instalación en `frontend/README.md`.
- `backend/`: API REST con Express y MongoDB (Entrega 3).

## Ejecutar el frontend

```bash
cd frontend
npm install
npm run dev
```
